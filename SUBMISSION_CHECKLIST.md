# NHSJS Submission Checklist

## Pre-submission

### Manuscript
- [ ] PDF compiled without LaTeX errors
- [ ] All figures present in PDF (no missing figure boxes)
- [ ] Abstract: under 250 words
- [ ] Author name and contact on title page
- [ ] Keywords listed
- [ ] All references cited in text
- [ ] All in-text citations match bibliography
- [ ] No placeholder text remaining
- [ ] Word count: 3,000–8,000 (currently ~3,400 body words)

### Figures
- [ ] `fig1_reliability_diagram.png` generated
- [ ] `fig2_bootstrap_distribution.png` generated
- [ ] `fig3_fairness_comparison.png` generated
- [ ] All figures referenced in text with `\ref{}`
- [ ] All figure captions complete and descriptive
- [ ] Figures readable at print size

### Code and data
- [ ] GitHub repository created and public
- [ ] `calibration_analysis.py` committed
- [ ] `figure_generation.py` committed
- [ ] `requirements.txt` committed
- [ ] `data/README.md` committed with dataset download link
- [ ] `README.md` committed with usage instructions
- [ ] Code availability URL in manuscript matches actual repo URL

### Overlap and originality
- [ ] OVERLAP_AUDIT.md reviewed — no high-risk overlap findings
- [ ] AI_WRITING_RISK_AUDIT.md reviewed — LOW risk confirmed
- [ ] No passages copied from prior manuscripts
- [ ] Contribution is distinct from all prior papers
- [ ] Framing is educational/investigative, not governance/policy

### NHSJS-specific
- [ ] NHSJS account created at nhsjs.com
- [ ] Submission category: Research Article
- [ ] High school student eligibility confirmed (if required)
- [ ] Cover letter written (optional but recommended)

## After submission
- [ ] Confirmation email received
- [ ] Submission ID recorded
- [ ] Expected review timeline noted (NHSJS typically 4–8 weeks)
- [ ] GitHub repo URL added to CV/application materials

## Cover letter notes (if writing one)

Keep it short — one paragraph. State:
- What the paper is about (one sentence)
- Why it matters (one sentence)
- That code and data are publicly available (one sentence)
- Confirm you are a high school student / independent researcher

Do NOT oversell or use marketing language. NHSJS reviewers respond better
to honest, specific framing than to claims about "transformative impact."
