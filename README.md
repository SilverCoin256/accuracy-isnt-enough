# accuracy-isnt-enough

Analysis code for *Beyond Accuracy: Investigating Confidence, Calibration, and Fairness Gaps in a Small Machine Learning Classifier*, submitted to the National High School Journal of Science.

Three classifiers trained on synthetic IBM HR data scored between 0.76 and 0.80 AUC. CatBoost still had 8.6% calibration error before correction. The analysis checks whether predicted probabilities match observed outcomes, how uncertain the AUC estimates are, and how errors differ across demographic groups.

## What's here

```
calibration_analysis.py   main analysis pipeline (AUC, ECE, bootstrap, fairness)
figure_generation.py      produces all three manuscript figures
requirements.txt          Python dependencies
data/README.md            how to get the dataset
figures/                  generated plots (SVG + PNG)
results.json              generated by the analysis
manuscript.tex            LaTeX source for the paper
```

## Quick start

```bash
pip install -r requirements.txt
```

Download `ibm_hr_attrition.csv` from Kaggle (link in `data/README.md`) and put it in `data/`, then:

```bash
python calibration_analysis.py   # writes results.json
python figure_generation.py      # reads results.json, writes figures/
```

CatBoost writes training logs to the ignored `catboost_info/` directory. Run the analysis before generating figures to plot your own results. Without `results.json`, the plotting script uses the manuscript values.

## Dataset

IBM HR Analytics Employee Attrition dataset. 1,470 synthetic employee records, 35 variables, binary attrition label (16.1% positive). Generated by IBM for educational purposes, publicly available on Kaggle. No real employees.

## What the analysis does

Trains Logistic Regression, Random Forest, and CatBoost on the dataset. Then runs three checks AUC doesn't run for you: (1) Expected Calibration Error before and after isotonic regression correction, (2) bootstrap confidence intervals on AUC using 1,000 resamples of the test set, and (3) Demographic Parity Difference and Equalized Odds Difference for gender and age groups.

The bootstrap confidence intervals for AUC were about 15–16 percentage points wide. CatBoost's equalized odds difference across age groups was 0.258.

## Notes on reproducibility

Random seed is 42 throughout. I got the same results on macOS and tested with the exact package versions in `requirements.txt`. If you use different versions (especially sklearn) you might get slightly different numbers but the qualitative findings should hold. More details in `reproducibility_notes.md`.

One thing to know: the first time I ran this I accidentally fit the isotonic calibration on part of the test set instead of a separate hold-out, which gave artificially good calibration numbers. The current version splits a calibration hold-out from the training set before the test set is ever touched. If you're adapting this, make sure to keep those splits separate.
