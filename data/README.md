# Data

This project uses the **IBM HR Analytics Employee Attrition & Performance** dataset.

Download from Kaggle:
https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset

Save the file as `data/ibm_hr_attrition.csv`. That's the path the analysis script expects.

The dataset is synthetic — IBM generated it for educational and demonstration purposes.
It contains 1,470 rows and 35 columns, with a binary `Attrition` column (Yes/No).
No real employee records are included.
